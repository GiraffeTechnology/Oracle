# ADR-008　不可回补权利的触发条件:争议,而非非终局

日期:2026-08-31
状态:**已采纳**(已落入 `ERCS/erc-xxxx.md`)
来源:作者裁定,驳回 HKEX 审计的 H-1

## 背景

HKEX 审计(`HKEX_RULE_CONFORMANCE_AUDIT_ZH.md`)建议引入登记册封闭,使记录时刻在事前终局。

作者驳回,理由:

> HKEX 赋予的公告权是董事会/股东会,这是一个预先知道的名单;链上治理主要依赖 DAO,DAO 的治理手段是投票,谁有权发起投票?谁有权投票?没有一个预知的名单,只能核查发起当时有没有这个权力。

## 决策

### 一、封闭机制不进标准

封闭需要一个**外生于登记册**的权威来宣告。HKEX 的董事会满足这一点:其成员资格不取决于名册上谁持有什么。DAO 不满足:发起权与投票权都源自持有,而持有正是投影要解析的对象。要求"被授权方宣告封闭"会形成循环 —— 必须先解析投影,才能确定谁有权封闭投影。

封闭降级为 Profile 可选项,仅适用于其登记册本身具备外生权威的场景,并须自带 HKEX 那样的提前公告与累计上限。这一点写进 Rationale,不进规范条款。

### 二、两类权利的闸门分开

| | 触发条件 | 理由 |
| --- | --- | --- |
| 可回补(分红) | `isFinalAsOf` 为假 → 递延 | 递延只花时间;终局是正确闸门 |
| 不可回补(投票、发起提案) | **被争议** → 拒绝并永久消灭 | 无法等待;非终局是常态,不能作闸门 |

**被争议**:代币上有打开的缺口,且该缺口的开启时刻 ≤ 所论瞬间。无结算接口的合约不存在缺口,也就不存在被争议的瞬间。

### 三、不可回补权利的行使规则

1. MUST NOT 以终局为闸门;
2. MUST 按行使当时的投影评估;
3. 实现 MUST 记录所依据的条目版本;
4. 后续准入 MUST NOT 追溯撤销已完成的行使。

第 4 条不可省:治理结果若可回滚,任何 DAO 都无法采用本标准。

## 被这条决策修正的错误

`ad2dd7b` 中的触发条件是"落在 projection gap 内"(与作者最初的裁定一致)。我在引入 `isFinalAsOf` 时把它改写为"`isFinalAsOf` 为假",把一个偶发条件换成了恒常条件 —— 当下时刻位于最新条目生效时刻之后,几乎永远非终局。按被改过的正文,DAO 在几乎任何时刻都不能发起提案或投票。

这是我引入的退化,已改回。

## 后果

- 规范正文小节改名为 "Exercising a right against the projection",新增"被争议"定义与三条规则;
- Rationale 新增两段:为何两半闸门不同,以及外生权威在链上不存在;
- 测试新增一项,证明"被争议"与"非终局"是两个可区分的状态,且取消缺口会结束争议但不产生终局;
- **接口未变**,三个 interface ID 保持 `0x3ce71a8d` / `0xfd0f6337` / `0x6d39b0a8`。

## 未采纳的选项

**加 `isContestedAsOf(tokenId, instant)` 访问器。** 该谓词可由 `openGapOf` + `settlement().openedAt` 两次调用得出,加访问器会第三次改动投影接口 ID。当前留在正文条款层面,不入接口,待作者决定。

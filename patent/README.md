# patent/

本目录存放与 `erc/` 中的提案对应的**专利申请文件**,与 ERC 提案是两条互相牵制的线:ERC 追求公开与互操作(CC0),专利追求排他权,而**公开一旦发生就不可撤回**。

| 目录/文件 | 内容 |
| --- | --- |
| `CN/` | 中国发明专利申请文件全套(请求书、摘要、权利要求书、说明书、附图)+ 内部检索报告 |
| `AUDIT_REPORT_INSERT_ZH.md` | 供并入 `AUDIT_REPORT_ZH.md` 的现成章节,含本工作流引入的**新增发布阻断项** |

**先读 `CN/00_申请文件清单与提交须知.md` 的第二节。** 那里记的是一个顺序约束,不是建议。

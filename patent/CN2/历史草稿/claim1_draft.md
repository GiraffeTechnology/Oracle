# 权利要求 1（工作流版，第二稿：按检索结果收窄）

一种无人值守断言系统的出具工作流控制方法，所述系统在无人工介入的条件下，就一个其记录内容不可公开的链外权威数据源的事实对外出具经签名的断言，其特征在于，在出具任一条断言之前，按下述固定次序依次评估全部前提，任一前提不成立即终止本次出具：

【前序部分——与现有技术共有】

P1 该事实所源自的数据源处于已注册且未被撤销的状态；
P2 该事实的取得时刻与当前时刻之差未超过该数据源声明的有效期；
P3 本次断言的内容承诺未曾被出具过，且该内容承诺与本次断言所许可的效果相绑定；

【特征部分——检索未见对应】

P4 内容边界：待出具内容中不含关于主体的合规结论，亦不含估值、价格、收益、信用或适当性结论；

P5 数据最小化：待出具内容仅含验证该事实所必需的承诺与引用，不含所述数据源的记录原文；

P6 校验器有效性：用于评估 P4 与 P5 的每一校验器，均已在本次运行中以其规范反例调用并返回拒绝；未返回拒绝者判定为失效，其所守护的出具一并被拒绝；

P7 变更授权：若本次出具将改变所述系统对外承诺的状态，则须已取得由两名不同主体作出的、且绑定于本次内容承诺的批准；

且其特征还在于：终止本次出具的表现为不产生签名，不得产生表示降级、部分成立或失败原因的经签名结果；不得以跳过任一前提、降低其判定强度、或改用未经上述全部前提的替代路径的方式完成本次出具。
